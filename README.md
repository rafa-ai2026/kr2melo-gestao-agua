# Sincronização por BKP

1. Faça um backup do sistema em uso antes de atualizar.
2. Extraia todo o pacote KR2MELO-BKP-Sincronismo. Abra o iniciador Windows incluído usando o mesmo navegador e perfil do sistema anterior. O pacote mantém as chaves de dados originais. Para site hospedado, atualize os arquivos no endereço existente.
3. Em **Fechamento**, clique em **Gerar BKP de sincronização**. Confira as leituras e confirme o lembrete de responsabilidade.
4. Guarde o arquivo e importe-o no celular. Confira prédio, competência e leituras. A geração do arquivo não comprova recebimento no celular e não envia à nuvem.
5. Faça o fechamento. A confirmação manual permite leituras locais ou pendentes; conflitos continuam exigindo resolução.
6. Após o fechamento, importe no celular o BKP da **nova competência**, com as leituras anteriores atualizadas, antes de iniciar a próxima rota.

Se houver leitura mais recente no celular, importe o BKP móvel no painel antes de fechar. Alterações de leitura, observação, horário ou competência invalidam a confirmação anterior: gere outro BKP.

O registro de responsabilidade fica na auditoria e no fechamento. Não transforma pendências de nuvem em envio confirmado. A confirmação só vale quando gravada com sucesso.

Foram aprovadas 101 verificações no motor do sistema, incluindo o caso de 32 leituras locais, cancelamento, conflitos, alteração de leitura, recarga e falha de gravação. As interfaces e o armazenamento foram simulados. Não houve validação em celular físico, nuvem real ou impressora nesta sessão.
